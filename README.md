# AWS E-commerce Infrastructure with Terraform 🚀

Este repositório contém a infraestrutura como código (IaC) para um ambiente de e-commerce escalável na AWS.

## 🏗️ Resumo da Arquitetura
* **VPC & Networking:** Subnets públicas e privadas, NAT Gateway e Internet Gateway.
* **Segurança:** Isolamento de camadas e roteamento inteligente.
* **Estado Remoto:** Configuração de Backend no S3 para colaboração segura.
